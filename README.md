# Pi‑Ener‑lite

  Pi‑Ener‑lite is a dedicated UPS power supply designed for the Raspberry Pi Zero series motherboards. It connects to the Zero board via 7 spring pogo pins, which handle both power delivery and data reading.

This UPS is powered by a standard flat‑top 18650 lithium‑ion cell. It seamlessly switches to battery power upon external power loss and supports simultaneous charging and discharging. Built‑in protections include overcharge, overdischarge, overcurrent, and short‑circuit protection, plus external power insertion detection.

In addition, Pi‑Ener‑lite integrates the fuel gauge chip CW2015 and the RTC real‑time clock chip DS1307. It can measure battery voltage and remaining capacity, and provide RTC timing function for Zero.


Pi-Ener-lite是一款专门为树莓派Zero系列主板设计的UPS电源，通过7根弹性顶针与Zero主板连接，供电以及数据读取都是通过顶针来完成。Pi-Ener-lite采用标准的平头18650锂电池进行供电，外部电源断电时无缝切换为锂电池供电，支持边充边放，支持过充、过放、过流、短路保护，以及外部电源插入检测。另外Pi-Ener-lite集成了电量计芯片CW2015以及RTC实时时钟芯片DS1307，可用于对电池电压、电量进行测量，以及为Zero提供RTC计时功能。
