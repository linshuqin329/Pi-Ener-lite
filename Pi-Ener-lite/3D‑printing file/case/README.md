> **Note**: Due to different shrinkage ratios of various printing materials, some printed parts of the enclosure may require manual trimming for smooth assembly.
> 
*Printing Recommendations*:
- Print the top case and base with the same material, e.g. PETG
- It is recommended to print the button cap, battery cover and pin header cover with PLA
  
<br><br>

> **注意**：由于不同打印材料的收缩比例不同，可能会导致外壳在组装过程中，部分打印部件需要手工修整才能顺利组装
> 
*打印建议*：
- 上壳跟底壳使用同一种材料打印，例如PETG
- 按键帽、电池盖、排针盖建议使用PLA打印
